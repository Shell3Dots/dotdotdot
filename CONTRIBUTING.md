# Contributing

Thanks for your interest in **dotdotdot**. Open an [issue](https://github.com/Shell3Dots/dotdotdot/issues) to report bugs, suggest features, or ask questions before large changes. Pull requests are welcome: fork the repo, create a branch from `main`, keep changes focused, and run `npm test` locally so CI stays green. Follow existing code style in `lib/` and `bin/`; avoid new dependencies unless there is a strong reason (the project is zero-dependency by design).
